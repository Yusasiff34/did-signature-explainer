# DID Signature Explainer

A simple educational tool for understanding DIDs, public keys, and cryptographic signatures.

Built as a contribution to Technocore and inspired by the work of @flop_labs.

## What this teaches

This tool demonstrates the relationship between a DID, a public key, and cryptographic verification.

It explains three important ideas:

- Proof of control of a cryptographic key
- Proof that a message has not been altered
- The difference between cryptographic proof and real-world identity

A cryptographic signature does not, by itself, prove that a particular human owns a key.

## Why I made this

When someone first encounters DIDs and cryptographic signatures, the relationship between a DID, a key, and a signature can be confusing.

I made this tool to give newcomers a simple interactive explanation instead of requiring them to understand complicated technical documentation first.
